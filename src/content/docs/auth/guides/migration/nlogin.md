---
title: "Миграция с nLogin"
---

Миграция поддерживает бесплатный nLogin `10.4.22` и новее.

## Что переносится

- Имя с исходным регистром;
- UUID;
- Пароль MD5, SHA256, SHA512, BCRYPT2Y, BCRYPT2A, ARGON2ID, ARGON2I или ARGON2D;
- Привязка к Discord;
- Дата регистрации;
- Дата и IP последнего входа.

## Перед началом

1. Сделайте резервную копию базы данных и папки nLogin.
2. Установите последнюю версию BaronessAuth.
3. Поместите исходную папку nLogin в `plugins/`. JAR можно удалить: для миграции нужна только папка.
4. Проверьте настройки базы данных nLogin. Они должны указывать на базу, из которой нужно перенести игроков.

## Перенос

1. Выполните `/auth migrate nLogin`.
2. Следите за сообщениями в консоли и проверьте все предупреждения.
3. Дождитесь создания файла `.backup` с импортированными данными.
4. Загрузите его командой `/auth backup load [файл]`. При необходимости добавьте `--force`.

После загрузки проверьте несколько профилей, вход по паролю и привязку Discord.
