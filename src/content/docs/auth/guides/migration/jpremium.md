---
title: "Миграция с JPremium"
---

Миграция поддерживает JPremium `CLEARED-1.23.0` и новее.

## Что переносится

- Имя с исходным регистром;
- UUID из столбца `uniqueId`, но не `premiumId`;
- Пароль SHA256;
- Статус premium;
- Дата и IP регистрации;
- Дата и IP последнего входа.

:::caution
JPremium нестандартно работает с UUID. BaronessAuth переносит только `uniqueId`.

После миграции может понадобиться `force-set-uuid` в `advanced.yml`, чтобы игроки всегда получали перенесённые UUID вместо стандартных пиратских.
:::

## Перед началом

1. Сделайте резервную копию базы данных и папки JPremium.
2. Установите последнюю версию BaronessAuth.
3. Поместите исходную папку JPremium в `plugins/`. JAR можно удалить: для миграции нужна только папка.
4. Проверьте настройки базы данных JPremium. Они должны указывать на базу, из которой нужно перенести игроков.

## Перенос

1. Выполните `/auth migrate JPremium`.
2. Следите за сообщениями в консоли и проверьте все предупреждения.
3. Дождитесь создания файла `.backup` с импортированными данными.
4. Загрузите его командой `/auth backup load [файл]`. При необходимости добавьте `--force`.

После загрузки проверьте несколько профилей: UUID, пароль, premium-статус и даты входа.
