Для настройки понадобится Telegram и файл `plugins/BaronessAuth/config/methods/telegram.yml`.

:::danger
Токен даёт полный доступ к боту. Не публикуйте его и не отправляйте посторонним.
:::

## Создание бота

1. Откройте диалог с [BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Укажите имя и username бота.
4. Скопируйте токен из ответа BotFather. Он выглядит примерно так: `123456789:ВАШ_ТОКЕН`.
5. Откройте `plugins/BaronessAuth/config/methods/telegram.yml`.
6. Установите `enabled: true` и вставьте токен в поле `token`.
7. Запустите прокси или выполните `/auth reload`.

Бот должен запуститься без ошибки в консоли и отвечать на сообщения.

## Форматирование сообщений

Параметр `bot / parse-mode` в `telegram.yml` задаёт формат сообщений. Подробный синтаксис описан в [Telegram Bot API](https://core.telegram.org/bots/api#formatting-options).

### `MARKDOWN`

Используется по умолчанию:

````markdown
**жирный**
__курсив__
`код`
~~перечёркнутый~~
```блок кода```
||скрытый текст||
````

### `MARKDOWN_V2`

Поддерживает больше возможностей, но требует экранировать частые символы, включая `.` и `!`. Без правильного экранирования Telegram отклонит сообщение. Синтаксис есть в [документации MarkdownV2](https://core.telegram.org/bots/api#markdownv2-style).

### `HTML`

Позволяет форматировать сообщения HTML-тегами. Список доступных тегов находится в [документации HTML-режима](https://core.telegram.org/bots/api#html-style).

## Обязательная подписка

BaronessAuth может требовать подписку на канал или участие в чате перед использованием бота.

### 1. Получите ID канала или чата

1. Откройте Telegram Desktop.
2. Перейдите в `Настройки` → `Продвинутые` → `Экспериментальные настройки`.
3. Включите `Show Peer IDs in Profile`.
4. Откройте канал или чат, нажмите на его название и скопируйте ID.

![ID канала в профиле Telegram Desktop](/docs/assets/auth/guides/telegram/channel-id.webp)

### 2. Настройте конфиг

Добавьте ID в `plugins/BaronessAuth/config/methods/telegram.yml` без кавычек:

```yml
bot:
  require-channel-subscription:
    enabled: true
    ids:
      - ID канала или чата
    message: '⛔ Для использования бота вы должны подписаться на <вставьте своё>.'
```

### 3. Добавьте бота

1. Добавьте бота в канал или чат.
2. Назначьте его администратором. Дополнительные права не нужны.
3. Запустите прокси или выполните `/auth reload`.

После этого проверьте бота с подписанного и неподписанного аккаунта.
