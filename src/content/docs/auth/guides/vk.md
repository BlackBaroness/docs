title: "Бот ВК"

Для создания бота нужны права владельца или администратора сообщества ВК.

:::danger
Ключ доступа даёт частичный доступ к управлению сообществом. Не публикуйте его и не отправляйте посторонним.
:::

## Создание бота

### 1. Откройте настройки сообщества

![Переход в настройки сообщества ВК](/docs/assets/auth/guides/vk/community-settings.webp)

### 2. Включите сообщения

Откройте раздел `Сообщения` и включите сообщения сообщества.

![Включение сообщений сообщества ВК](/docs/assets/auth/guides/vk/enable-messages.webp)

### 3. Включите возможности ботов

Откройте `Сообщения` → `Настройки для бота` и включите возможности ботов.

![Включение возможностей ботов ВК](/docs/assets/auth/guides/vk/enable-bot-features.webp)

### 4. Создайте ключ доступа

Откройте `Дополнительно` → `Работа с API` и начните создание ключа.

![Создание ключа доступа в настройках API ВК](/docs/assets/auth/guides/vk/create-access-key.webp)

Выберите права, показанные на скриншоте.

![Права ключа доступа для бота ВК](/docs/assets/auth/guides/vk/access-key-permissions.webp)

Скопируйте ключ и сохраните его в безопасном месте. После закрытия страницы получить этот ключ повторно нельзя — придётся создать новый.

![Созданный ключ доступа сообщества ВК](/docs/assets/auth/guides/vk/copy-access-key.webp)

## Настройка BaronessAuth

Откройте `plugins/BaronessAuth/config/methods/vk.yml` и заполните `token`:

```yml
enabled: true

bot:
  token: 'ваш ключ доступа, в кавычках'
```

Запустите прокси или выполните `/auth reload`. Бот должен запуститься без ошибки в консоли.

## Обязательная подписка

BaronessAuth умеет требовать подписку на сообщество перед использованием бота.

1. Откройте главную страницу настроек сообщества и скопируйте ID.

   ![ID сообщества для проверки подписки ВК](/docs/assets/auth/guides/vk/community-id.webp)

2. Добавьте ID в `plugins/BaronessAuth/config/methods/vk.yml` без кавычек:

   ```yml
   bot:
     require-group-subscription:
       enabled: true
       ids:
         - ID сообщества
       message: '⛔ Для использования бота вы должны подписаться на <вставьте своё>.'
   ```

3. Запустите прокси или выполните `/auth reload`.
4. Проверьте бота с подписанного и неподписанного аккаунта.
